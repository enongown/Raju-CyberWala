EXPLORE ARUNACHAL - SIMPLE SEARCH SITE

This site searches existing records across these tables when they exist:
places, Locations, Tourist_Destinations, Hotels, Restaurants,
Medical_Facilities, Police_Stations, Transport, Local_Foods.

INSTALL:
1. Extract this ZIP.
2. Copy the folder `explore_arunachal_simple_search` to your XAMPP `htdocs` folder,
   commonly C:\xampp\htdocs\
3. Start Apache and MySQL from XAMPP Control Panel.
4. Confirm database `explore_arunachal` exists.
5. If needed, edit db.php (default XAMPP: root, blank password, port 3306).
6. Open http://localhost/explore_arunachal_simple_search/

Use the search box to search across fields, or choose a specific table.
The site only reads data; it does not modify or delete records.
It displays up to 100 records per table per search to keep the demo responsive.
It skips tables that do not exist yet.
